Hierarchical Hydrogen Permeation Model¶

Reference documentation for a steady-state analytical model of hydrogen permeation through an oxide-coated structural alloy wall: what each level does, why it is done that way, and the equations behind it.

Note

Scope. This documents the method, not any result.

  • It applies to any metal/oxide wall the configuration can describe, not only the study that happens to be active.

  • Every figure is drawn from a small fictitious system — the Example Wall — or is a labelled schematic. No figure reports a real run.

  • Real numbers do appear, confined to blocks marked Worked values or Design choices, where a measured number is the only honest justification for a threshold. Those are regenerated from the live model and diffed, so they cannot go quietly stale.

Checked against Python 3.9.23, NumPy 1.26.4, SciPy 1.13.1, matplotlib 3.9.4, pandas 2.3.3, SALib 1.5.0, Sphinx 7.4.7 — 2026-10-09, at commit 1fcd605.

Re-check it all:

python docs/figures/check_equations.py     # 44 / 44 checks passed
python docs/figures/make_figures.py        # 20 / 20 figures written
python docs/_tools/verify_docs.py          # clean
python docs/_tools/worked_values.py --check
cd docs && make html                       # -W: warnings are errors

Important

Read Two models, not six levels before comparing any two levels. Levels 1–5 and the L6 family describe the same wall under different physics, and a conclusion does not carry across that fork. It is the most common way to misread this model.

The running example¶

Every figure and every equation check runs on the Example Wall: a fictitious system with round-number properties, defined in docs/figures/example_wall.py. It is not a real material. It was chosen so that each intermediate quantity can be checked by hand, the oxide and metal carry comparable resistance, and the Level 2b interface pressure has an exact closed form to test the solver against.

Symbols in the text are generic — \(D_m\), \(K_s\), \(\alpha\). The project’s own identifiers (D_metal, f_pinhole) appear only in Appendices B and C, the code map, and examples.

Provenance¶

Note

The theory chapters and how-to guides were authored from the project’s earlier design notes, with every factual claim re-checked against the current code. That absorption is complete — the original notes have been retired.

The pages with uppercase filenames (Complete Parameter Reference, Complete Output Reference, Steady State, Transients, and the Accumulation Model, Validating the Trapping Block Against TDS, Packaging decisions — hydrogen-model:1.0.0 offline container, Hydrogen Permeation Model — Offline Analysis Environment) are generated or release-record documents. They stay at the repository root so they remain readable on GitHub, and are included here by reference rather than copied, so there is one source of truth for each.

docs/CHECKPOINT.md holds the working state of the documentation itself — decisions settled, progress, what is still open. It is deliberately not part of this site.
