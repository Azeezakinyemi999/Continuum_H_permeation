oxide_permeation — Levels 2-3: molecular transport through the oxide¶

calculations.oxide_permeation.molecular_diffusion_flux(D_ox, K_ox, thickness, P_up, P_down)[source]¶

Calculate flux through oxide layer via molecular diffusion.

This is fundamentally different from metal permeation: - H2 molecules diffuse intact (don’t dissociate) - Concentration is linear in pressure (Henry’s law) - Results in flux linear in pressure difference

Parameters:

  • D_ox (float) – Molecular diffusion coefficient in oxide (m²/s)

  • K_ox (float) – Henry’s law constant for H2 in oxide (mol/m³/Pa)

  • thickness (float) – Oxide layer thickness (m)

  • P_up (float) – Upstream pressure (Pa)

  • P_down (float) – Downstream pressure (Pa)

Returns:

Flux through oxide (mol/m²/s)

Return type:

float

Notes

C = K_ox * P (Henry’s law, NOT Sieverts’ law) J = -D * dC/dx = D * (C_up - C_down) / thickness

calculations.oxide_permeation.calculate_oxide_resistance(D_ox, K_ox, thickness)[source]¶

Calculate permeation resistance of oxide layer.

Resistance is defined such that: Flux = ΔP / Resistance

For molecular (Henry’s-law) transport the resistance is independent of pressure:

\[R_{ox} = \frac{L_{ox}}{D_{ox} K_{ox}}\]
Parameters:

  • D_ox (float) – Molecular diffusion coefficient in oxide (m²/s)

  • K_ox (float) – Henry’s law constant (mol/m³/Pa)

  • thickness (float) – Oxide thickness (m)

Returns:

Oxide resistance (Pa·s·m²/mol)

Return type:

float

Note

This resistance is pressure-independent (linear transport)

calculations.oxide_permeation.calculate_metal_resistance(D_metal, K_s_metal, thickness, P_interface)[source]¶

Calculate permeation resistance of metal layer.

The metal resistance depends on the interface pressure, because Sieverts’ law makes the flux law nonlinear in \(P\). This is a KEY DIFFERENCE from oxide resistance.

Parameters:

  • D_metal (float) – Atomic diffusion coefficient in metal (m²/s)

  • K_s_metal (float) – Sieverts’ constant (mol/m³/Pa^0.5)

  • thickness (float) – Metal thickness (m)

  • P_interface (float) – Pressure at oxide/metal interface (Pa)

Returns:

Metal resistance at given interface pressure (Pa·s·m²/mol)

Return type:

float

Notes

For metal with Sieverts’ law: J = (D * K_s / thickness) * (√P_up - √P_down)

Linearizing around P_interface: .. math:

R_{metal} \approx \frac{2 L \sqrt{P_{int}}}{D K_s}

This is an approximation valid for small ΔP across metal.

calculations.oxide_permeation.get_oxide_properties_at_T(oxide_name, temperature_K, oxides=None)[source]¶

Calculate temperature-dependent oxide properties.

Uses reference-temperature Arrhenius format:

k(T) = k_ref × exp((-E/R) × (1/T - 1/T_ref))

Parameters:

  • oxide_name (str) – Name of oxide material (e.g., ‘Cr2O3’)

  • temperature_K (float) – Temperature in Kelvin

  • oxides (dict, optional) – Registry to look oxide_name up in. Defaults to model_config.OXIDES; pass another study’s OXIDES dict to resolve names it defines instead.

Returns:

Contains D_ox, K_ox, thickness at specified temperature

Return type:

dict
